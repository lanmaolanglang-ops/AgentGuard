## 验证入口

20内ag:validation-python运行标准Schema/fixture/迁移与语义检查。18内ag:crypto-python和ag:crypto-node独立计算21向量。跨文档审查内ag:document-audit-python运行count/hash/链接/任务/证据检查。下方真实Mermaid parser逐图解析，使用已有VS Code模块，无安装或DOM补丁。

所有Mermaid节点使用ASCII ID，中文解释在相邻正文。该写法适配现有headless parser，本次解析检查不等于图像渲染/视觉审美验收。

<!-- ag:mermaid-node -->

~~~javascript
import fs from 'node:fs';
import path from 'node:path';
import {pathToFileURL} from 'node:url';
const modulePath = 'C:/Users/烧冬瓜的Mac/AppData/Local/Programs/Microsoft VS Code/7debcd0e2a/resources/app/extensions/markdown-language-features/markdown-editor-out/mermaid.core-S5KCHHL2.js';
const mermaid = (await import(pathToFileURL(modulePath).href)).default;
mermaid.initialize({startOnLoad:false,securityLevel:'strict'});
const root = 'D:/AgentGuard/docs/p0.1';
const results = [];
for (const file of fs.readdirSync(root).filter(name => name.endsWith('.md')).sort()) {
  const text = fs.readFileSync(path.join(root,file),'utf8');
  let index = 0;
  for (const match of text.matchAll(/~~~mermaid\s*\n([\s\S]*?)\n~~~/g)) {
    index++;
    try {
      await mermaid.parse(match[1]);
      results.push({file,index,parsed:true});
    } catch(error) {
      results.push({file,index,parsed:false,error:String(error)});
    }
  }
}
const failures = results.filter(result => !result.parsed);
console.log(JSON.stringify({count:results.length,passed:results.length-failures.length,failures,results}));
if(failures.length) process.exitCode=1;

~~~
