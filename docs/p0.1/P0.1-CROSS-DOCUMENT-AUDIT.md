# P0.1跨文档审查

AgentGuard V2.0 P0.1 · 修订日期 2026-11-05

## 审查范围与方法

阶段0固定15原始文件的名称/字节/SHA-256，阶段1逐份完整读取全部P0正文。阶段2–3建立AG追踪矩阵并区分修订、新增和废弃歧义。阶段4–7修订边界、Broker、协议、Windows、UI/测试和依赖。阶段8–10从最终Markdown提取结构，执行标准Schema、独立密码学、Mermaid parser、引用/DAG/证据等级检查后生成验收。

本表12项为十个工作包之外继续追踪的跨文档问题，包含新增合同二次审查发现。已修复文档合同不表示相关运行攻击已通过。

## 规范优先级与字段审查

16定义等级/flag/scope，07定义正式结构，18定义编码/MAC，15定义执行时序和状态，17/19定义资源边界实验，10/14定义验收和依赖。各规范负责不同维度，发生冲突必须停止相关许可并修订。

已核对策略所需身份、runtime/adapter/provider/config、cwd/targets、input/environment/stdin、network、native_permission、nonce/epoch/grant/prepared全部具有正式字段或明确Core内部合同。parent rule管理API尚未开放，I06需先定义闭合管理Schema，不允许从extensions补值。未取得最终字段的A入口不得获得强参数绑定或连续授权。

UI只显示当前有效能力，runtime证书与合成fixture分开。所有拟运行保证均映射到I06/I07及AT17–46等实际测试。Windows/Agent实验没有被本地文档验证替代。
