标准验证使用已有python-jsonschema 4.26.0、Draft202012Validator、FormatChecker及本地URN registry，无安装。65夹具中的28反例被拒绝，37正例通过，无结果与预期冲突。8个旧版本迁移清除许可/认证，64状态对符合授权终态规则。严格parser另拒绝重复键、浮点/指数/-0、溢出、NaN/Infinity、孤立代理、BOM、深层、帧/数组/map超限13类输入，另有正向安全整数例。

Node v24.19.0与Python stdlib对21向量的typed字节、frame和HMAC全部一致，公开key仅测试。CV17/18插入顺序不同但编码一致，CV20/21在secret-v2域。Rust尚未实现。

Mermaid使用既有VS Code mermaid.core-S5KCHHL2.js逐图parse，11图通过，无DOM补丁/软件安装。未渲染图像，本次只验收语法和依赖边。现有模块有Node模块类型警告，不影响parse结果，未修改VS Code。
